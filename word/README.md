# 오골계 워드 0.1.4 (뼈대)

HWP/HWPX 편집기(rhwp) + PDF 줄바꿈 복원 보기. 모든 처리가 이 컴퓨터 안에서만 일어난다.

## 처음 설치 (Windows 기준)

Node.js 20 이상이 필요하다(`node -v` 로 확인).

```bash
npm install          # Electron 과 필요한 라이브러리 설치
npm run get-model    # Kiwi 한국어 모델(약 88MB)과 그림 속 글자 읽기(OCR) 언어 자료(약 6MB) 받기 — 처음 한 번
npm start            # 오골계 워드 실행
```

Electron 없이 브라우저로 확인하려면 `npm run serve` 후 http://127.0.0.1:7801/app/ 을 연다.

## 화면

- 시작하면 빈 문서 하나가 열린다. 새 문서·열기·저장은 편집 화면의 **파일** 메뉴를 쓴다(Ctrl+S 등 단축키도 편집 화면 것).
- 편집 화면 메뉴 줄의 **서브뷰** 메뉴(도구 옆)로 오른쪽에 하나 더 연다.
  - PDF 열기… → 변환해서 PDF 보기 창으로(창 안의 "변환" 버튼으로 원본/변환 보기 전환)
  - 문서 열기… / 새 문서 → 두 번째 편집기(그 편집기의 파일 메뉴로 따로 저장)
  - 서브뷰 닫기(또는 서브뷰 칸 오른쪽 위 ✕)
  - 파일을 서브뷰 칸에 끌어다 놓아도 된다(.pdf / .hwp / .hwpx)
- 가운데 분할바를 끌어 폭을 바꾼다.

## PDF 여는 방식(빠르게)

- 앱을 켤 때 Kiwi 한국어 모델을 뒤에서 미리 불러 둔다(PDF 를 처음 열 때 기다리지 않게).
- PDF 를 열면 글자와 이미지 위치만 먼저 뽑아 **원본 보기가 바로** 뜬다. 쪽 그림은 화면에 보이는 쪽만 그때그때 그린다.
- 줄바꿈 복원과 원본 글꼴 되살리기는 뒤에서 하고, 끝나면 "변환" 단추가 켜진다. 변환 화면도 보이는 쪽만 그때그때 만든다.
- 그림 속 글자: 글자 데이터가 있으면(기울어진 카드의 글자 등) 그대로 쓰고, 픽셀로만 된 그림은 변환 보기에서 그 쪽이 보일 때
  뒤에서 로컬 OCR(Tesseract, Apache-2.0, 한국어·영어)로 읽는다. 그림은 원본 그대로 두고 읽은 글자를 같은 자리·기울기에 투명하게 겹쳐
  드래그·복사할 수 있다. 그림 위 오른쪽 클릭 → "이 그림의 글자 변환 끄기/켜기". 지도 선 위 큰 글씨 등은 OCR 이 놓칠 수 있다.
- 서버 구조: `core/session.js`(열린 PDF 하나), `core/viewer-shell.js`(가벼운 보기 화면), `/pdf/<id>/…` 경로

## 테마

플랫 화이트 + 테마색 하나. 편집 화면의 **보기** 메뉴 맨 아래 "테마색"에서 10가지 중 고르거나 직접 고른다(기본: 올리브그린).
고른 색은 편집 화면·서브뷰·PDF 창에 한 번에 적용되고 설정 파일에 저장된다(Electron: 사용자 데이터 폴더의 settings.json).

## 편집 화면 꾸미기

로컬 서버가 편집 화면(rhwp-studio)을 내보낼 때 `renderer/studio-theme.css` 와 `renderer/studio-bridge.js` 를 끼워 넣는다.
rhwp 소스는 건드리지 않으므로 rhwp 를 새 버전으로 올려도 그대로 적용된다.

- `studio-theme.css`: 편집 화면의 `--ui-*`, `--color-*` 변수를 흰 바탕과 테마색(`--og-accent`)으로 덮어쓴다. 도구 막대 그라데이션·그림자 제거.
- `studio-bridge.js`: 주 문서 편집 화면의 메뉴 줄에 "서브뷰" 메뉴를, 보기 메뉴에 "테마색"을 넣고, 누르면 앱에 알린다.

## 구조

| 파일 | 역할 |
|---|---|
| `main.js` | Electron 창, 파일 열기·저장 대화상자 |
| `preload.cjs` | 화면에 대화상자 기능만 열어 줌 |
| `server.js` | 127.0.0.1 로컬 서버: 편집 화면, 앱 화면, PDF 변환(`/api/pdf`), 빈 문서(`/api/blank`) |
| `renderer/` | 앱 화면(서브뷰, 분할바) + 편집 화면에 끼워 넣는 테마·메뉴(studio-theme.css, studio-bridge.js) |
| `core/` | PDF 복원 엔진(pdf-text-core 0.6.4 와 같음) |
| `vendor/rhwp-studio/` | rhwp 편집 화면(v0.8.6, 로컬 빌드, 외부 웹폰트 끔). `npm run build-studio` 로 다시 빌드 가능 |

편집 화면은 `file:` 주소에서 동작하지 않아서(rhwp 제약) 앱 안에서 로컬 서버를 띄워 불러온다. 서버는 127.0.0.1 에만 열리고 포트는 실행할 때마다 빈 포트를 고른다.
